# ToonNest

A responsive classic animation website with user authentication, role-based access, and an admin dashboard.

## Features

- User login and authentication using DummyJSON
- Role-based navigation for Admin and User accounts
- Admin dashboard for user management
- Browse classic animated movies
- Movie details and video playback
- Search and Continue Watching
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- DummyJSON API
- Local Storage
